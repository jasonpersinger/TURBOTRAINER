GS4 TurboTrainer
bulk skill training for gemstone iv v0.3.0 · updated 2026-05-08 04:27 EDT

Install

⚡ GS4 TurboTrainer
Drag this button to your bookmarks bar.
If the bar is hidden: Ctrl+Shift+B / ⌘+Shift+B

Usage

  1. Log in to GSIV and open the Skills Trainer via the GOALS command
  2. Click ⚡ GS4 TurboTrainer in your bookmarks bar
  3. ±1, ±5, ±10 buttons appear next to every skill
  4. A sub-row beneath each skill adds: type a rank to jump straight to it, type a delta to add/subtract, or use quick buttons: 0, 1x, 2x, 3x, max
  5. Submit your training as normal when done
